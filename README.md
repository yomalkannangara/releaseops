# ReleaseOps

ReleaseOps is a production-style service, incident, and deployment management platform built as a combined Software Engineering and DevOps portfolio project.

The platform allows teams to manage software services, report and track incidents, and view deployment history. Its CI/CD pipeline will automatically report successful and failed deployments back to the ReleaseOps dashboard.

## Core Features

- User authentication and role-based access control
- Software service management
- Incident tracking and status management
- Deployment history with Git commit information
- Audit logging
- Automated CI/CD deployment reporting
- Health monitoring and failed-release rollback

## Technology Stack

- React and TypeScript
- Java and Spring Boot
- PostgreSQL
- Spring Security, JWT and RBAC
- Docker and Docker Compose
- GitHub Actions and GitHub Container Registry
- Oracle Cloud Infrastructure
- Terraform
- Nginx and HTTPS
- Prometheus and Grafana
- Trivy security scanning
